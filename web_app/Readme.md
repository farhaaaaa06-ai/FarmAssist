# FarmAssist: Web Application Service

The web application module provides real-time browser-based plant leaf pathology diagnostics using deep learning and multi-lingual reporting.

---

## Getting Started

### 1. Install Dependencies
Ensure you have Python 3.8+ installed:
```bash
pip install -r requirements.txt
```

### 2. Verify Model Weights
Ensure `plant_disease_model_1_latest.pt` is placed in this directory.

### 3. Launch Local Server
Execute the application entrypoint:
```bash
python app.py
```
Access the application by navigating to `http://localhost:5000` in your web browser.
